## Featured Projects

### Linux SOC Lab — Splunk (https://github.com/AdhyanRaghav/splunk-linux-soc-lab)

A hands-on SOC home lab focused on Linux security monitoring and log investigation.

- Collects and analyzes Linux authentication logs.
- Uses SPL searches to investigate events and identify suspicious activity.
- Explores security monitoring, dashboards, and alerting workflows.

### File Integrity Checker (https://github.com/AdhyanRaghav/File_Integrity_Checker)

A Python-based tool for monitoring file integrity on Linux systems.

- Uses SHA-256 hashes to identify file-content changes.
- Tracks metadata such as file size, modification time, and inode information.
- Monitors permissions and ownership details.

### Mini Vulnerability Scanner (https://github.com/AdhyanRaghav/mini-vulnerability-scanner)

A Python-based web vulnerability scanner for basic security checks.

- Checks HTTP security headers and cookie attributes.
- Looks for information disclosure and potentially exposed sensitive files.

### AI-Gated Encrypted Secure Folder (https://github.com/AdhyanRaghav/AI-Gated_Encrypted_Secure_Folder-Linux-)

A Linux security project combining face authentication with encrypted folder access.

- Uses face authentication as an access-control step.
- Supports encrypted folder access.
- Implements automatic locking based on mount activity and inactivity.
